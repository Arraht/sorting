# Car Catalog & Sorting CLI

Консольное Java-приложение для генерации, хранения и обработки данных об автомобилях
с использованием собственных реализаций коллекций (`CustomArrayList` и `CustomHashMap`).

## Архитектура и структура проекта

* `src/main/resources/cars.json` — эталонный каталог марок и моделей автомобилей (только для чтения).
* `data/` — директория рабочих файлов пользователя (по умолчанию используется `data/user_cars.json`).
* `program.util` — кастомные реализации коллекций (`CustomArrayList<E>`, `CustomHashMap<K, V>`), поддерживающие Stream API и стандартные интерфейсы `List` и `Map`.
* `program.util.sort` — интерфейс стратегии сортировки (`SortStrategy`), построитель составных компараторов (`CarComparatorBuilder`) и реализации алгоритмов:
  * `BubbleSort` — пузырьковая сортировка (используется по умолчанию).
  * `SelectionSort` — сортировка выбором.
  * `InsertionSort` — сортировка вставками.
* `program.dto` — модели данных:
  * `BrandCarsDto` — структура для чтения справочника (марка + список моделей).
  * `CarDto` — модель конкретного автомобиля для рабочего файла (марка, модель, мощность в л.с., год выпуска).
* `program.parser` — парсеры JSON на базе регулярных выражений без сторонних библиотек (`CarJsonParser`, `WorkFileParser`).
* `program.service` — бизнес-логика генерации и сохранения данных (`CarFileGenerator`).

## Доступные команды

После запуска `Main` приложение переходит в интерактивный режим ожидания команд (`>`).

| Команда | Описание | Пример ввода |
| :--- | :--- | :--- |
| `help` | Показать список доступных команд | `help` |
| `file [имя_файла]` | Показать текущий активный файл или переключиться на другой файл в папке `data/` | `file test` |
| `fill all` | Заполнить рабочий файл всеми машинами из каталога (мощность и год генерируются случайно) | `fill all` |
| `fill random <кол-во>` | Заполнить рабочий файл указанным количеством случайных машин из каталога | `fill random 5` |
| `fill car <марка> <модель>` | Заполнить рабочий файл одной конкретной машиной со случайными характеристиками | `fill car BMW X5` |
| `add manual <марка> <модель> <мощность> <год>` | Добавить одну машину (марка и модель должны быть в каталоге) | `add manual BMW X5 340 2020` |
| `add file <имя_файла>` | Добавить все машины из другого файла в папке `data/` в рабочий файл | `add file garage_bmw` |
| `add random` | Добавить в рабочий файл одну случайную машину из каталога | `add random` |
| `sort [алгоритм] <поле1> [поле2] [поле3]` | Отсортировать рабочий файл по 1–3 полям (`brand`, `model`, `power`, `year`) и перезаписать его | `sort brand power year` |
| `exit` | Корректно завершить работу приложения | `exit` |

### Работа с несколькими файлами (команда `file`)

По умолчанию при запуске программы активен файл `data/user_cars.json`. 
С помощью команды `file` можно создать или переключиться на любой другой рабочий файл 
в директории `data/` (расширение `.json` добавляется автоматически):

```text
> file
> file garage_bmw
> fill car BMW X5
```

### Флаги режимов записи (для команды `fill`)

По умолчанию, если текущий рабочий файл уже существует, программа запросит подтверждение
на перезапись (`y` / `n`). Это поведение можно изменить с помощью необязательных флагов в конце команды:

* `--append` — дописать новые автомобили в конец существующего файла без удаления старых данных.
* `--force` — принудительно перезаписать существующий файл без запроса подтверждения.

**Примеры использования команды `fill`:**
```text
> fill random 3 --force
> fill car TOYOTA Land Cruiser 300 --append
> fill all --append
```

### Каскадная сортировка (команда `sort`)

Сортировка доступна только после создания рабочего файла и при наличии в нём **более одного автомобиля**.
Вы можете выбрать от **1 до 3 уникальных полей** из списка `brand`, `model`, `power` (или `horsepower`),
`year` в любом порядке — при совпадении значений первого поля сравнение автоматически переходит ко второму, а затем к третьему.

Необязательным первым аргументом можно указать алгоритм: `bubble` (по умолчанию), `selection` или `insertion`.

**Примеры использования команды `sort`:**
```text
> sort power
> sort brand power
> sort selection brand power year
> sort insertion year model power
```
